# Privacy verification map

Each user-facing privacy promise, the code that keeps it, and the
test that proves it. Update this file when a flow changes.

## Promises

| Promise                                                | Implementation                                                                                                                                           | Test                                                                                                                                                                                                              |
| ------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Saving a key sends only the key                        | `testModelsEndpoint` issues `GET /v1/models` with an auth header and no body (`src/providers/index.ts`)                                                  | `sends the key probe with a timeout signal` (`src/providers/index.test.ts`); keyless panel tests assert the models call leaves first                                                                              |
| Nothing leaves before Agree                            | `assertConsent` gates identify, alternates, and segmentation; previews stay placeholders pre-consent (`src/providers/index.ts`, `src/sidepanel.tsx`)     | `shows the consent gate without any network call`, `blocks without consent or a key`, `refuses remote work when privacy settings fail to load`                                                                    |
| Image-only mode withholds page text                    | `formatSignalsForPrompt` returns a fixed marker and the footer names the reduced payload (`src/providers/index.ts`)                                      | `withholds page text in image-only mode and handles empty signals`                                                                                                                                                |
| The full page address is never sent                    | Only slugified topic and filename words ride the prompt; canonical and page URL stay local (`src/injected/collect_signals.ts`, `src/providers/index.ts`) | `formats signals with labels and skips empties` (asserts the address is absent and the topic words present)                                                                                                       |
| Hostile image addresses never serialize                | Blob, file, and filesystem URLs fall back to page text (`src/providers/index.ts`)                                                                        | `recovers text-only for hostile image URLs without serializing them`                                                                                                                                              |
| Previews load without cookies, after consent only      | Credential-less fetch behind the consent check with blob cleanup (`src/sidepanel.tsx`)                                                                   | Preview consent tests in `src/sidepanel.test.ts`                                                                                                                                                                  |
| One-time host grants are removed and verified          | Journaled grants with refcounted borrowers, verified revoke, and a startup sweep (`src/grants.ts`)                                                       | `revokes at zero and deletes the verified entry`, `retains failed revocations for later reconciliation`, `sweeps held but unjournaled origins`                                                                    |
| Keys are encrypted with a non-extractable wrapping key | AES-GCM ciphertext in extension storage, wrapping key in IndexedDB (`src/key_vault.ts`)                                                                  | `round-trips a key through encrypted local storage`, `treats tampered ciphertext as an orphan and keeps it`                                                                                                       |
| Cache keys are hashes with bounded retention           | SHA-256 over identity fields, 1/7/30-day TTL, 10 slots, 2 MB cap (`src/result_cache.ts`)                                                                 | `serves repeat images from cache without provider calls`, retention and clear tests in `src/sidepanel.test.ts`                                                                                                    |
| Costs are estimates, never exact figures               | `≈` run line and `Estimated` monthly total (`public/_locales/en/messages.json`)                                                                          | Rendered by every result run; `message catalog integrity` pins the keys                                                                                                                                           |
| Cancellation cannot start later paid work              | Ticket invalidation, canceled sequences, and ownership checks (`src/sidepanel.tsx`)                                                                      | `cancels a hanging identify from the loading card`, `discards a late ready after canceling collection`, `keeps the newer result when a canceled identify resolves late`                                           |
| Known spend survives retries, cancel, and supersession | Settle-before-ownership with run-plus-stage dedup (`src/run_state.ts`, `src/sidepanel.tsx`)                                                              | `clears loading while the body stalls and settles the late body quietly`, `drops a superseded identify that resolves after the next run wins`, `serializes concurrent settles on one run without double-counting` |
